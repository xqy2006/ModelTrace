接入 OrcaRouter

两种方式获得同一把 sk-orca-… 密钥，任选其一即可。

OrcaRouter - API

API Key

已有密钥？直接粘贴，模型归因请求会以 Bearer 方式带上它。

密钥只保存在本机，不写入仓库，也不会回显。

OrcaRouter - Auth

OAuth 2.0 + PKCE

没有密钥？用 OrcaRouter 账户授权，浏览器里点一次即可，不需要 client secret。

授权码使用 S256 PKCE 校验，10 分钟内单次有效；换回的密钥是长期有效的普通 API Key，不会被自动刷新。
